The archive

Every version of SKYGEAR that has ever been playable, kept at exactly the bytes it shipped with. They are a record of how the game got here, not alternatives to the current one — if you are here to play, play v11. Each build is pinned by hash and the build script refuses to regenerate it, so v4's controls are still the controls its playtesters had.

Why the old ones are still here. Every build comes off one shared core, so an engine edit aimed at the current version silently re-emits all the older ones — which is how v2 and v3 ended up carrying lane code they never ran, and how v4's controls changed months after anyone played it. Each shipped build is now pinned by hash and the build script writes only the live one. A version you played is the version you played.
